# Supplementary original-book images

Two institutional image editions supplement the reader. They are different witnesses, not the Taisho print edition, and do not remove the 554 SAT identifiers without CBETA number candidates. No SAT database text, directory dataset or images are republished.

- **勝鬘經義疏**, NIJL Ukai collection, 1649 Tahara Nizaemon edition, source 200019041: 80 institutional canvases, catalogue extent 77 leaves/one volume. The individual record marks Public Domain Mark and has no exception URL. The displayed full-region IIIF representation is 2880×1920, preserving text and original kana/reading marks and red annotations.
- **顯戒論**, Kyoto University Main Library, 1617 Sonzon edition, RB00009556: 173 institutional canvases in groups 01–03. The library catalogue says three volumes/three books, while the cover says six volumes; the site preserves this distinction and does not silently reinterpret it. The source's free-reuse rule requires attribution, backlink and a processing note. The displayed full-region source JPEGs are 2000×1333.

All 253 obtained representations total 126,821,010 bytes. Local hashes, dimensions, JPEG start/end markers, and the complete institutional sequence were verified. Every file was uploaded to a content-addressed key in the existing CANON_STORAGE bucket and fully read back with matching SHA256. Images are excluded from GitHub and the Worker bundle; the catalogue contains only provenance and fixed asset references.

The reader displays the original Han-character pages, including original reading marks, without OCR or AI translation. Page numbers are institutional image positions, not inferred Taisho page/line references. A complete digital sequence does not prove the physical book has no missing leaves; no full human textual collation is claimed.

Browser checks used isolated desktop Chrome and a 390px viewport, including actual HTTP/CSP and actual JPEG decoding. These are not physical iPhone tests. Preferences remain in this browser, without registration or automatic navigation to an old page.
