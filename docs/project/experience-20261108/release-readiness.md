本轮新增自有界面与统计代码，不上传练习历史、账户、私人语料或第三方影像原件至Git；不改凭据、数据库或23个生产绑定。

## 实修仪表盘

参考Insight Timer官方的连续练习及累计练习里程碑机制：[里程碑](https://help.insighttimer.com/support/solutions/articles/67000698008-how-do-milestones-work-)，[统计设置](https://help.insighttimer.com/support/solutions/articles/67000714307-can-i-customize-my-stats-in-the-app-)。没有复制其会员界面或音库。

显示今日5分钟目标、每日行动、连续天数、近30天实修日历、近7天与前7天时长、累计实际时长与练习日、下一里程碑。每天累计实际静坐至少60秒才算练习日，300秒达成每日5分钟目标；所有结束方式均计实际秒数。今天尚未练习可接续截至昨天的连续天数，不补签。跨日记录按开始日归档，不按墙钟区间猜测暂停后的每日时长。图表使用全部本机历史，不被明细筛选或分页扭曲；详细数据表与统计口径始终可达。

行动入口仅安排5分钟或1分钟，需核对后手动开始；不接管现有练习。记录关闭、保护数据、未保存进度、导入及删除保持原边界。源码测试采用独立合成记录，不使用用户截图中的实际记录。

## Zen计时五轮

1. 放大真实进度圆圈、数字；标题降为无障碍语义。
2. 收纳声音、全屏、历史及帮助至“声音与工具”，保留即时静音。
3. 隐藏常规底部说明，保留未知错误、时间异常及保存问题的可见状态；180分钟时使用适合六位数字的字号。
4. 手机、短屏、横屏及减少动态效果规则；音频错误可从紧凑入口进入处理。
5. 回归真实计时、暂停、恢复、关闭工具、危险状态和偏好保存。四轮定向9/100/100/113项分别通过，第五轮完整实践392项通过。

## 原本影像阅读

默认100dvh阅读视窗；紧凑翻页、页码、更多设置与手势触发的原生全屏。来源、许可、加工与版本说明保留可达入口。新图确认加载/解码后才更新页码、URL和本机位置；失败/取消/乱序不得保存错误页。保持缩放和视窗位置，后退不新增history项；无JS链接仍有效。清除记忆撤销旧初始加载及在途解码的保存权限，新明确操作才可恢复记忆。原图颜色不变，不OCR、不AI翻译。
