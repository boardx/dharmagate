# Real recording assets

These recordings retain their original rights; they are not covered by an application-code license. See `licenses.json` for exact source URLs, authors, hashes and changes.

- BambooBeast, SingingBowl1 and SingingBowl2: author's public-domain dedication (PD-self), released on Wikimedia Commons in 2008. Files here are Commons' official MP3 transcodes.
- jonopodmore, Mokugyo.wav: CC0-1.0. File here is the public HQ MP3 preview linked from the author's Freesound page, not the original WAV.

No recording has been generated by this application. The instrument illustrations are decorative original artwork, not photographs of a recording session. Technical decoding tests are distinct from human listening and physical iPhone tests.

Pixabay candidates are not included in this public asset directory. Do not add licensed stock audio to a public raw-asset library solely because it is free to download or has been cropped. Background music needs its own provenance, license and integration review.

Run `node apps/web/src/practice/build-recordings.mjs --check` from the repository root to verify the fixed reviewed inputs and generated module. No network access or private material is needed.
