# Explicit-source evidence search integration

This increment implements keyword BM25, optional scoped hybrid RRF and exact citation validation. It does not configure a model, grant content rights, discover private files or certify semantic relevance.

Use `createPublicCanonSearch` with at most 32 explicitly admitted existing Chinese reader units, an existing `readVerifiedUnit` service and independent live `readRights`. Each admission pins source commit, raw SHA and the existing `readingModel` SHA. The caller must supply an audited TEI parser/verified reader; the structured preview renderer is not an interchangeable flattening service. The adapter independently verifies original bytes and reading SHA, reconstructs existing juan-local pagination, and grants only display/search. Publication eligibility alone never implies search, embedding or RAG permission.

Compose `createEvidenceSearchHandler({service,enabled:true,scopeLabel})` before the legacy fallback for exact `/resources/search`, `/api/evidence-search/*` and owned asset routes. All other routes return null. Serve the existing shared site navigation stylesheet. The production origin remains `https://dharmagate.us`; do not weaken CSRF checks for previews. Do not enable the page until a real admitted source service is connected. Scope text must name the actual bounded subset, never claim whole-canon indexing.

The lexical repository performs resource eligibility before BM25 corpus statistics and rereads every eligible source before returning. Generic repositories must implement `scopedRetrieval:true`, invoke `isEligible`, and return the pinned source fingerprint. An actual vector provider must independently partition/filter its retrieval and statistics before candidate generation; the marker alone is not proof of tenant safety. Cache hits recheck current actor, rights, source hashes, index/model versions. No query text is placed in browser URLs/local storage.

Model answers need separately approved RAG sources, an explicit answer policy, real versioned provider and budget reservation/settlement. Attempts charge budget even on rejected output or timeout. Timeout cannot prove a third party stopped execution. Exact quoted citations establish provenance, not semantic entailment; human relevance/support review and real provider latency/cost evaluation remain pending. No private first-ten corpus is admitted.

Validation: `node --test apps/web/test/evidence-search-core.test.mjs apps/web/test/evidence-search-http.test.mjs apps/web/test/evidence-search-canon.test.mjs`. All text in these tests is synthetic, not scripture or private account data. The separate `evidence-search-loopback.test.mjs` exercises real synthetic loopback HTTP; sandbox listening initially failed EPERM and the same command passed after normal approved escalation. Neither HTTP mode establishes physical mobile/browser or production acceptance. DG016–023/027/040 remain subject to actual source integration, rights, human benchmark and production evidence.
